# 🩺 ECG Signal Analysis and Fourier Transform Exploration

## 📘 Project Overview
This project was developed as a practical application following the completion of the first **Digital Signal Processing (DSP)** course on Coursera.  
The course covered fundamental signal concepts, time and frequency domain analysis, and **Fourier Transforms**.

The main goal of this project is to **reinforce the learned DSP principles** using Python’s scientific libraries by analyzing real biomedical signals (ECG) from both time and frequency perspectives.

While the project is **not a production-level or clinical system**, it serves as an important **learning step** toward mastering biomedical signal processing — forming part of my **annual study plan in Artificial Intelligence**.

---

## 🎯 Objectives
- Apply core DSP concepts using Python.  
- Visualize ECG signals in the time domain.  
- Compute and interpret the **Fourier Transform** of biomedical data.  
- Extract basic statistical and frequency-domain features.  
- Build a foundation for future work (filtering and AI-based signal analysis).

---

## 🧠 What I Learned
- How to process real biomedical signals using Python.  
- The relationship between time-domain and frequency-domain representations.  
- How noise and sampling affect the accuracy of extracted features.  
- How to prepare data for the next phase of filtering and machine learning.

---

## 🧰 Technologies & Libraries
- **Python**
- **NumPy** – numerical processing  
- **Pandas** – data handling and statistics  
- **Matplotlib / Seaborn** – visualization and plotting  
- *(Later to include)* `scipy.signal` for filtering  

---

## 🩻 Project Workflow
1. **Data Loading:** Import ECG data from open datasets.  
2. **Visualization:** Plot ECG signal in the time domain.  
3. **Fourier Transform:** Compute frequency-domain representation.  
4. **Feature Extraction:** Calculate metrics like mean, variance, and dominant frequencies.  
5. *(Next Phase)* Apply filtering techniques once the second DSP course is completed.

## 📊 Dataset Source
The ECG data used in this project is sourced from Kaggle:  
**[Heartbeat Dataset by Shayan Fazeli](https://www.kaggle.com/datasets/shayanfazeli/heartbeat)**  
This dataset contains ECG recordings categorized into normal and abnormal heartbeats, suitable for biomedical signal analysis and classification tasks.
